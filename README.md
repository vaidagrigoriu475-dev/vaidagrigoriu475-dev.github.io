# HANBAOROU

Personal site for [vaidagrigoriu475-dev.github.io](https://vaidagrigoriu475-dev.github.io/).

GitHub Pages publishes the built site from the `/docs` folder on `main`. The React source stays in `src/`.

```bash
npm install
npm run dev
npm run build
```

`npm run build` writes the static files to `docs/`, including `404.html` so client-side routes such as `/works` still open after a refresh.
